# progetto-hackhub-ids
progetto HackHub per il corso di Ingegneria del Software UNICAM a.s. 2025/2026. 

Requisiti: Java 21 (o quello che userete), Maven/Gradle, IntelliJ.

Struttura:

docs/     documenti UP
backend/  codice Spring Boot
scripts/  script utili


Flusso Git:

creare branch da main → lavorare → commit/push → Pull Request → review → merge.

Regole messaggi commit (brevi e con prefisso):
docs: …, feature: …, fix: …, chore: …

Contributo: usare Issues + PR, 1 review obbligatoria.
